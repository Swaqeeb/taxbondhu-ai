# TaxBondhu AI
### Bangladesh Personal Income Tax Assistant

TaxBondhu AI aims to help Bangladeshi taxpayers prepare understandable,
verified personal income tax returns through a guided conversation.

## First Prototype
- Salaried taxpayer with one employer
- Assessment Year: 2026–27
- Income Year: 2025–26
- Synthetic financial data during initial development

## Planned Features
- Simple questions, one at a time, in Bangla or English
- Relevant document requests and verified information extraction
- Deterministic calculations based on verified official NBR rules
- Checks for missing information and inconsistent figures
- Traceable calculations and clear explanations
- A reviewed return summary and guided online filing

## Accuracy Principles
Never guess missing information or assume eligibility.
Unresolved issues must be flagged before final approval.
Complex or ambiguous cases require professional review.
No return is guaranteed error-free.

## Privacy
Real taxpayer documents, identifiers, credentials, and API keys
must never be committed to this repository.

## Development Status
Day 1 — 11 October 2026: Project planning and documentation.
No tax calculation rules have been implemented or validated yet.
Online form filling and direct submission remain subject to
verification of NBR permission and technical feasibility.
